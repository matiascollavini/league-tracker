# rcp-fe-lol-leagues[¶](https://leonkraim.github.io/rcp-fe-lol-documentation-26.09/plugins/rcp-fe-lol-leagues/#rcp-fe-lol-leagues "Permanent link")
Feature Plugin
**Leagues/ranked UI** — displays ranked progression, league tiers, and promotion animations.
## Overview[¶](https://leonkraim.github.io/rcp-fe-lol-documentation-26.09/plugins/rcp-fe-lol-leagues/#overview "Permanent link")  
| Property  | Value  |  
| --- | --- |  
| **Plugin**  | `rcp-fe-lol-leagues`  |  
| **Type**  | Feature  |  
| **Loading**  | Non-lazy  |  
| **Aliases**  | None  |  
| **Role**  | Ranked/Leagues Interface  |  
## Purpose[¶](https://leonkraim.github.io/rcp-fe-lol-documentation-26.09/plugins/rcp-fe-lol-leagues/#purpose "Permanent link")
Provides the ranked leagues interface showing player rank, league points, division progression, promotion/relegation animations, and rank-specific visual effects. Includes celebration animations for each rank tier.
