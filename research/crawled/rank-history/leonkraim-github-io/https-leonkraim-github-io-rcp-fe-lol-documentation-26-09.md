# Riot Games FE - League of Legends Client Documentation[¶](https://leonkraim.github.io/rcp-fe-lol-documentation-26.09/#riot-games-fe-league-of-legends-client-documentation "Permanent link")
About This Documentation
This site provides a comprehensive deep-dive analysis of the **League of Legends client frontend** codebase. All code is extracted from the `FE_raw` folder containing production Webpack bundles, CSS, and manifests. **43 plugins documented** with all classes, functions, and APIs.
* * *
## What Is This?[¶](https://leonkraim.github.io/rcp-fe-lol-documentation-26.09/#what-is-this "Permanent link")
The League of Legends client is built as a **micro-frontend plugin system**. Each feature (settings, profiles, social, navigation, etc.) is an isolated plugin that communicates through a shared dependency injection container. This documentation covers all **43 plugins** and their underlying architecture.
