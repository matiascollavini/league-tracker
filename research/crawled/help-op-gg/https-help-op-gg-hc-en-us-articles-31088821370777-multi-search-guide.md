# Q. What is Multi-Search?
The Multi-Search feature allows multiple Summoner Names to be entered at once, enabling quick access to each summoner's recent stats, tier, win rate, and more on a single screen.
![2.png](https://help.op.gg/hc/article_attachments/48970535793945)
# Q. How to search using Multi-Search
## **Multi-Search tab**
Click the [Multi-Search] tab from the main menu, then enter each Summoner Name separated by commas. Enter the full Riot ID (nickname + tagline) accurately to search.
![3.png](https://help.op.gg/hc/article_attachments/48970535795609)
## **Summoner search bar**
In the Summoner search bar, enter Summoner Names separated by commas to search.
