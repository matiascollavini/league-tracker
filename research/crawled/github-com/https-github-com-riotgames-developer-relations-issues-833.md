> believe the original article mentioned that a free name change is going from 1 month to 1 year so it should be less likely that a player changes their riot id.  
>  Curious to hear about if there are other cases that might require frequent name lookups.
As a player yourself, how would you feel if you changed name and you'd still be called your old name for months to come?  
A more aggressive cache window just isn't the solution.
Having summonercore maintain an up-to-date version of someone's Riot ID can be a good alternative cause it offers us the same feature set we already have and optimize for, without any compromises.
Another thing to mention that was pointed out to me: We were the first post on /r/league for almost 3 days straight and we appeared on the LCS, both of them resulting in insane spikes in our traffic. With the new limits, we would've lost more than half of our new users from those days, resulting in really bad player experience (for something that is 100% outside our control). With our current limits and our caching solution, we were able to handle both of these traffic surges with ease.
Riot recommends us to smooth out our traffic and try not to cause any spikes. The name to ID endpoints are the only ones we cannot control, we need to be able to have spikes in the event of reddit hugs (or lolesports hugs?)
